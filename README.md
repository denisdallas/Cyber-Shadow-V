# Cyber Shadow V

Retro-styled, top-down cyberpunk stealth action web game inspired by Hunter Assassin.

Navigate hazard-rich patrol grids, execute silent automatic proximity strikes, avoid guard vision cones and laser traps, and survive the endless descent — all inside a fully installable Progressive Web App (PWA).

**Live demo:** [cyber-shadow-v.vercel.app](https://cyber-shadow-v.vercel.app)

## Features
- Top-down stealth gameplay
- Guard vision cones & laser traps
- Automatic proximity strikes
- Endless descent progression
- Installable PWA

## Tech Stack
- TypeScript
- Vite
- Bun

## Development

```bash
bun install
bun run dev
```
